Local market sizing guide

Starter

~4 cores / 16 GB / 256 GB SSD — dev/test or very light production.

Standard (local mid)

~8 cores / 32 GB / 512 GB SSD — typical local mid-sized OLTP (<10k txn/day).

Upper local

~16 cores / 64 GB / 1 TB SSD — busier local production; common max box.

Growth / Enterprise

Only when Market reach is Regional or Enterprise — beyond usual local hardware.

OLTP / Transactional

SSD + buffer cache RAM; moderate MAXDOP; backups first for local market.

Mixed / Reporting

More CPU/RAM; prefer replica for heavy reports so OLTP stays stable.

E-commerce / SaaS

Size for peaks; pooling and cache reduce DB pressure.

Batch / IoT / CMS

Storage or job-window CPU dominate; HADR often lighter if restartable.
